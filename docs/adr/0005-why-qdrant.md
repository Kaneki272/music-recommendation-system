# ADR 0005: Why Qdrant

## Context
We need to perform sub-millisecond Approximate Nearest Neighbor (ANN) searches over millions of dense vector embeddings generated by our deep learning models.

## Decision
We chose Qdrant as our Vector Database.

## Consequences
- **Pros:** Built in Rust (fast), native support for payload filtering (crucial for filtering out already-listened songs), easy REST/gRPC API.
- **Cons:** A newer player in the vector DB space compared to Milvus or Faiss.
